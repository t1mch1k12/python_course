# Flask + MySQL: объединённая авторизация

## Установка

1. Установите MySQL и Python 3.10+.
2. В MySQL выполните `schema.sql`, например: `mysql -u root -p < schema.sql`.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Настройте переменные окружения `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` (по умолчанию localhost, root, пустой пароль, flask_auth). Настройте `SECRET_KEY` на случайную длинную строку.
5. Создайте пользователя: `python create_user.py`. Введите, например, `admin` и `12345`.
6. Запустите: `python app.py` и откройте http://127.0.0.1:5000.

## Логика

`index.html` отправляет POST на `/login`. Flask проверяет пустые поля, запрашивает пользователя из MySQL через `Database.get_user`, сверяет пароль с хешем, создаёт сессию и перенаправляет на `/login_page`. Ошибки показываются на форме. `/login_page` доступен только при наличии сессии, `/logout` завершает её.

## Важно

Пароли в БД хранятся в виде хешей, поэтому **не используйте** старый SQL `INSERT ... '123456789'`: такая запись не сможет войти с `check_password_hash`. Создавайте пользователей через `create_user.py`. Если уже добавили старую запись, удалите её или обновите хеш. Для реального развёртывания отключите `debug=True`, задайте секретный ключ через окружение, включите HTTPS и CSRF-защиту.
